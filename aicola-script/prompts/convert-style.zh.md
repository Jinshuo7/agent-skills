任务：为可乐AI（aicola.cn）项目写"自定义风格"的五项提示词，以及世界观设定。可乐AI会把这些文字自动加到每一次视频和图片生成里，所以只写画风和规则，不写剧情。

输入文件（只以这些为准，不要加入你自己的知识）：
- 画风说明：{STYLE_FILES}
- 故事文件（只用来写世界观，不用来定画风）：{STORY_FILES}

参考：可乐AI自带的预设"视频通用提示词"长这样（这是真人实拍预设，画风不要照抄，只学结构）：

```
【视频风格】真人短剧，影视实拍风格，……
【剧情节奏】……
【画面一致性】严格保持光影色调、人物受光、环境曝光前后一致，人物形象、服装、配饰保持连续统一。
【人物表现】人物面部稳定，五官清晰，动作连贯自然，无穿模，无卡顿，无人物变形。
【角色限制】禁止生成重复人物、同款分身、双胞胎效果，同一画面每个角色仅出现一次。
【镜头语言】……
【画面限制】无字幕，无文字，无Logo，无水印，无BGM。
```

要写的七项：

1. 视频通用提示词：用上面七个【】小标题。【视频风格】按画风说明写；【剧情节奏】按故事的节奏写（不要照抄"爽点强烈、高反转"）；【画面一致性】【人物表现】【角色限制】可以沿用预设原句；【镜头语言】按画风说明写；【画面限制】照抄"无字幕，无文字，无Logo，无水印，无BGM。"
2. 角色图片通用提示词：角色参考图的画风、线条、上色、背景、光照。不写版式、姿势、构图（版式由平台设置决定）。
3. 群像角色图片通用提示词：群像参考图的画风，同上。
4. 场景图片通用提示词：场景图的画风、光照、色彩。场景图里不要人物。
5. 其他对象图片通用提示词：道具图的画风、背景。道具图里不要人物、不要手。
6. 世界观：故事发生的时代、地点、社会背景、运行规则，3-6句，只用故事里给出的事实。
7. 整体美术：一句话概括画风（和第1项一致）。

拿不准的情况：画风说明里没有的东西（比如色板、线条粗细）不要编，写不出的就少写。画风说明完全没有时，第1-5项都只写一行"未提供画风"，第7项同样。

不要：不写剧情、角色名、地名；不写颜色以外的具体物件；不改动任何文件；不加解释。
