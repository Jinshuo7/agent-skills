# 可乐AI（aicola.cn）剧本输入格式规则

这份规则说明怎样把任何故事写成可乐AI解析效果最好的剧本。可乐AI会把剧本拆成集、场、小节（每节最长30秒），提取角色、场景、道具三类对象（每个对象可有多个版本），给每个对象生成参考图，再把每个小节的文字连同参考图交给 Seedance 生成视频。

## 1. 全剧结构（顺序固定）

```
# 《片名》

**类型：……**
**时长：约N分钟**

---

# 全剧梗概
# 角色设定
# 群体设定        （有群体时才写）
# 生物设定        （有非人生物时才写）
# 机械设定        （有机器人、载具角色时才写）
# 其他对象设定    （重要道具，可选）
# 剧本
# 第1集
## 1-1场
## 1-2场
……
```

- 短片只写 `# 第1集`。长剧每集一个 `# 第N集`，各自单独成行。
- 场号写成 `## 集号-场号场`，例如 `## 1-3场`。

## 2. 全剧梗概

5-8句，按时间顺序，只写发生了什么。不写主题、不写评价、不写给观众的话。

## 3. 角色设定（每个角色一节）

可乐AI用这些字段给角色生成参考图。字段空着，它就会自己编（颜值、发型、服装都会被编出来），所以每个字段都要写满，写看得见的事实。

```
## 角色甲
种族：人类
地区：……
年龄：……
性别：……
颜值：……
身份：……
年代：……
长相：脸型、眉眼、鼻、唇、肤色、明显特征
妆容：……
身材：身高、体型
穿着：从上到下，颜色和材质
发型：……
配饰：……
版本：默认版本名；其他版本名（第几场起，变化是什么）
说话方式：……
```

- 原故事没给的外貌信息写"未指定"，不要自己编。
- 只出声不出镜的角色（广播、电话另一端、旁白）照样建一节，外貌字段写"无"，在身份里写"只有声音"。
- 群体（士兵、人群、怪物群）写进 `# 群体设定`，名字以"群像"结尾，例如 `守卫群像`。
- 非人生物写进 `# 生物设定`，种族写"非人生物"，其余字段写看得见的形态。

## 4. 每场开头的五行（每场都写，没有就写"无"）

```
**场景：地点名，时间，内/外。**
**人物：角色甲，角色乙（受伤）。**
**群体人物：守卫群像。**
**声音角色：角色丙。**
**其他对象：道具一，道具二（损坏）。**
```

- 这五行只用来提取对象，不会进入视频文字。所以时间、闪回等信息还要在下面的描述说明里再写一次。
- 地点名用中文，简短固定。同一地点全剧只用一个名字；不同地点不要用相近的名字（会被合并）。
- 同一地点在不同时间样子不同，靠"时间"区分：`地点一，夜` / `地点一，清晨`。闪回写 `地点一，多年前`。

## 5. 名字：一物一名，处处一致

- 每个角色、群体、地点、道具全剧只用一个名字，在设定、五行、描述、动作、台词里拼写完全一致。可乐AI靠名字把参考图贴到画面上。
- 两个名字指同一个东西，会被拆成两个对象；一个名字指两个东西，会被合并。
- 角色名可以保留原文（英文名照写）。地点和道具用中文。
- 外观变化用版本名，写在名字后面的中文括号里：`角色甲（面具）`、`角色甲（摘下面具）`、`道具一（损坏）`。版本名在五行和动作里都要写。没有变化就不写括号。

## 6. 描述说明

每场五行之后写一段：

```
{描述说明：这一场开始时画面里看得见的东西。地点的样子、光线、天气、谁在哪里。时间或闪回在这里写明，例如"多年前，……"。}
```

不能写：给观众的话（"观众会明白……"）、和别的场对比（"与1-2场形成对比"）、"不要……"、镜头术语、抽象概念。

## 7. 动作

- 一行一个看得见的动作，放在中文括号里：`（角色甲推开铁门。）`
- 现在时，具体，能画出来。不写心理活动、不写比喻、不写抽象词。
- 只写原故事里有的动作和细节。不加颜色、伤口、距离、血、天气等原文没有的东西。
- 镜头只在剧情需要时写，写成一行动作：`（镜头从高处俯拍三人走进黑暗。）` 不写镜号、秒数、表格。

## 8. 台词

```
角色甲（语气）："台词"
角色乙（通讯/冷静）："台词"
角色丙（画外音/低声）："台词"
```

- 说话人名字必须和设定、五行里完全一致（版本括号可以省略）。
- 台词保留原文语言。英文台词照写英文，不翻译。
- 原文没有的台词不要加。

## 9. 长度和切分

- 可乐AI把一场切成若干30秒以内的小节，一个满30秒的小节大约600-800字。
- 一场写成大约一个完整的动作段落，300-900字。太长的场在剧情转折处拆成两场。
- 一场之内不要跳时间。闪回单独成场。

## 10. 不要写进剧本的东西

镜号、秒数、表格、"Shot"、"CUT TO"、导演备注、括号里的英文说明、"（注：……）"、给读者的解释、和其他场的对比、"不要/禁止"类句子、Markdown 表格和列表符号。
