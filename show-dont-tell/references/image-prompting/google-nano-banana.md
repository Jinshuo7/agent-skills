# Google Nano Banana Pro and Nano Banana 2.x (Gemini image models) prompting (official sources)

*Version note: the Gemini API image-generation page names **Nano Banana 2.1** (`gemini-nano-banana-2.1`) as the current model ("An update to Nano Banana 2… Recommended for all new projects to use Nano Banana 2.1"), alongside Nano Banana 2 Lite (`gemini-3.1-flash-lite-image`), Nano Banana 2 (`gemini-3.1-flash-image`, "previous-generation high-efficiency workhorse") and Nano Banana Pro (`gemini-3-pro-image`).* [https://ai.google.dev/gemini-api/docs/image-generation](https://ai.google.dev/gemini-api/docs/image-generation)

## (a) Prompt structure and order, length, plain vs keyword style

- On the newest model page, the model is described as delivering "significant improvements in visual quality, prompt adherence, multi-turn character consistency, and text rendering" versus Nano Banana 2 [https://aistudio.google.com/docs/models/gemini-nano-banana-2.1](https://aistudio.google.com/docs/models/gemini-nano-banana-2.1)
- The maker's own order for the base prompt: "To achieve the best results and have more nuanced creative control, include the following elements in your prompt:" — Subject → Composition ("How is the shot framed?") → Action → Location → Style → Editing Instructions [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Advanced elements come after that base: "Composition and aspect ratio: Define the canvas." / "Camera and lighting details: Direct the shot like a cinematographer." / "Specific text integration" / "Reference inputs" [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Prose, not keyword soup: "Describe the scene, don't just list keywords." and "A narrative, descriptive paragraph will almost always produce a better, more coherent image than a simple list of disconnected words." [https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/](https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/)
- On length/detail: "Describe a scene in rich detail. The more specific you are, the more control you have over the results." [https://ai.google.dev/gemini-api/docs/image-generation#1-photorealistic-scenes](https://ai.google.dev/gemini-api/docs/image-generation#1-photorealistic-scenes)
- "Be Hyper-Specific: The more detail you provide, the more control you have." [https://ai.google.dev/gemini-api/docs/image-generation#best-practices](https://ai.google.dev/gemini-api/docs/image-generation#best-practices)
- "Use Step-by-Step Instructions: For complex scenes with many elements, break your prompt into steps." [https://ai.google.dev/gemini-api/docs/image-generation#best-practices](https://ai.google.dev/gemini-api/docs/image-generation#best-practices)
- Simple prompts are not deprecated: "While simple prompts still work, achieving professional results requires more specific instructions." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Say that you want an image: "Prompt for images: Describe the intent by using phrases such as "create an image of" or "generate an image of". Otherwise, the multimodal model might respond with text instead of the image." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-best-practices](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-best-practices)

## (b) Using reference / input images: how many, how to refer to them, how to give roles

- "Nano Banana models allow you to mix up to 14 reference images." [https://ai.google.dev/gemini-api/docs/image-generation#use-14-images](https://ai.google.dev/gemini-api/docs/image-generation#use-14-images)
- The 14 are budgeted by role: on Nano Banana 2.1 / Gemini 3.1 Flash Image "Up to 10 images of objects with high-fidelity to include in the final image" and "Up to 4 images of characters to maintain character consistency"; on Gemini 3 Pro Image "Up to 6 images of objects", "Up to 5 images of characters", and "Up to 3 images to be used as style references" (that style-reference row is "N/A" for 2.1 / 3.1 Flash Image) [https://ai.google.dev/gemini-api/docs/image-generation#use-14-images](https://ai.google.dev/gemini-api/docs/image-generation#use-14-images)
- Hard cap restated in the cloud docs: "For best results using Gemini 3 Pro Image, include a maximum of 14 images in an input." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations)
- Official GitHub note: "You can mix multiple images (up to 3 with Nano-Banana 2 Lite, up to 14 with Nano-Banana 2 and Pro, 6 with high fidelity)" [https://github.com/google-gemini/cookbook/blob/main/quickstarts/Get_Started_Nano_Banana.ipynb](https://github.com/google-gemini/cookbook/blob/main/quickstarts/Get_Started_Nano_Banana.ipynb)
- Give each image a role in the prompt — the maker's own wording: "Reference inputs: When using uploaded images, clearly define the role of each. (e.g., "Use Image A for the character's pose, Image B for the art style, and Image C for the background environment.")" [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Numbered reference style is used in the API templates: "Take the [element from image 1] and place it with/on the [element from image 2]." [https://ai.google.dev/gemini-api/docs/image-generation#4-advanced-composition-combining-multiple-images](https://ai.google.dev/gemini-api/docs/image-generation#4-advanced-composition-combining-multiple-images)
- Ordinal reference style is also used ("the first image", "the second image"), e.g. in the reference-role example: "Creating a new image by combining the elements from the provided images" / "Take the blue floral dress from the first image" [https://ai.google.dev/gemini-api/docs/image-generation#4-advanced-composition-combining-multiple-images](https://ai.google.dev/gemini-api/docs/image-generation#4-advanced-composition-combining-multiple-images)
- Ordering matters for canvas shape: "If you upload multiple images with different aspect ratios, the model will adopt the aspect ratio of the last image provided." [https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/](https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/)

## (c) Keeping a composition or layout from an input image (edit vs generate, "keep everything else the same", camera/framing/scale)

- Edit vs generate are separate documented modes: "Image generation (text-to-image)" versus "Image editing (text-and-image-to-image)"; in the edit mode you "Provide an image and use text prompts to add, remove, or modify elements, change the style, or adjust the color grading." [https://ai.google.dev/gemini-api/docs/image-generation#gemini-image-editing](https://ai.google.dev/gemini-api/docs/image-generation#gemini-image-editing)
- On Vertex the edit mode is stated the same way: "Gemini generates an edited version of the provided image based on your description." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-edit-images](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-edit-images)
- The model is described as inheriting the input's look: "Provide an image and describe your change. The model will match the original image's style, lighting, and perspective." [https://ai.google.dev/gemini-api/docs/image-generation#1-adding-and-removing-elements](https://ai.google.dev/gemini-api/docs/image-generation#1-adding-and-removing-elements)
- The maker's own "keep everything else the same" template for localized edits: "Using the provided image, change only the [specific element] to [new element/description]. Keep everything else in the image exactly the same, preserving the original style, lighting, and composition." [https://ai.google.dev/gemini-api/docs/image-generation#2-inpainting-semantic-masking](https://ai.google.dev/gemini-api/docs/image-generation#2-inpainting-semantic-masking)
- The framing of that technique: "Conversationally define a "mask" to edit a specific part of an image while leaving the rest untouched." [https://ai.google.dev/gemini-api/docs/image-generation#2-inpainting-semantic-masking](https://ai.google.dev/gemini-api/docs/image-generation#2-inpainting-semantic-masking)
- The official sketch path (line-art input → painted frame): "Upload a rough sketch or drawing and ask the model to refine it into a finished image." [https://ai.google.dev/gemini-api/docs/image-generation#6-bring-something-to-life](https://ai.google.dev/gemini-api/docs/image-generation#6-bring-something-to-life)
- Its template keeps named features and adds the rest: "Turn this rough [medium] sketch of a [subject] into a [style description] photo. Keep the [specific features] from the sketch but add [new details/materials]." [https://ai.google.dev/gemini-api/docs/image-generation#6-bring-something-to-life](https://ai.google.dev/gemini-api/docs/image-generation#6-bring-something-to-life)
- Style-transfer template preserves layout explicitly: "Preserve the original composition but render it with [description of stylistic elements]." [https://ai.google.dev/gemini-api/docs/image-generation#3-style-transfer](https://ai.google.dev/gemini-api/docs/image-generation#3-style-transfer)
- Iteration wording the maker recommends: "Keep everything the same, but change the character's expression to be more serious." [https://ai.google.dev/gemini-api/docs/image-generation#best-practices](https://ai.google.dev/gemini-api/docs/image-generation#best-practices)
- Camera/composition control is prompt language, not a setting: "Control the Camera: Use photographic and cinematic language to control the composition. Terms like `wide-angle shot`, `macro shot`, `low-angle perspective`." [https://ai.google.dev/gemini-api/docs/image-generation#best-practices](https://ai.google.dev/gemini-api/docs/image-generation#best-practices)
- Scale/canvas defaults: "By default, the model matches the output image size to that of your input image, or otherwise generates 1:1 squares." [https://ai.google.dev/gemini-api/docs/image-generation#aspect-ratios-and-image-size](https://ai.google.dev/gemini-api/docs/image-generation#aspect-ratios-and-image-size)
- Position-lock wording appears in the maker's own showcase prompt: "change aspect ratio to 1:1 by reducing background. The character, remains exactly locked in its current position" [https://blog.google/innovation-and-ai/products/nano-banana-pro/](https://blog.google/innovation-and-ai/products/nano-banana-pro/)
- Sketch/blueprint input is claimed as a use case: "Whether turning sketches into products or blueprints into photorealistic 3D structures, you can now bridge the gap between concept and creation." [https://blog.google/innovation-and-ai/products/nano-banana-pro/](https://blog.google/innovation-and-ai/products/nano-banana-pro/)
- Thinking is on and is what plans the frame: "The model generates up to two interim images to test composition and logic. The last image within Thinking is also the final rendered image." [https://ai.google.dev/gemini-api/docs/image-generation#thinking-process](https://ai.google.dev/gemini-api/docs/image-generation#thinking-process)
- Not in official sources: any statement or option that guarantees exact reproduction of a layout sketch's camera, framing and scale (no composition-lock parameter or fidelity guarantee is documented; the guidance is prompt wording only).

## (d) Stopping the model from adding or inventing things (negative instructions, what works)

- The maker's documented technique is a positive rewrite, not a "no" list: "Use "Semantic Negative Prompts": Instead of saying "no cars," describe the intended scene positively: "an empty, deserted street with no signs of traffic."" [https://ai.google.dev/gemini-api/docs/image-generation#best-practices](https://ai.google.dev/gemini-api/docs/image-generation#best-practices)
- Restated on Vertex: "Describe what you want, not what you don't: Instead of saying "no cars", describe the scene positively by saying, "an empty, deserted street with no signs of traffic."" [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-best-practices](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-best-practices)
- The documented working alternative to negatives is scoping the edit: "change only the [specific element]… Keep everything else in the image exactly the same" [https://ai.google.dev/gemini-api/docs/image-generation#2-inpainting-semantic-masking](https://ai.google.dev/gemini-api/docs/image-generation#2-inpainting-semantic-masking)
- Same idea for identity/detail retention: "Ensure that the features of [element from image 1] remain completely unchanged." [https://ai.google.dev/gemini-api/docs/image-generation#5-high-fidelity-detail-preservation](https://ai.google.dev/gemini-api/docs/image-generation#5-high-fidelity-detail-preservation)
- Detail preservation is achieved by over-describing the thing to keep: "To ensure critical details (like a face or logo) are preserved during an edit, describe them in great detail along with your edit request." [https://ai.google.dev/gemini-api/docs/image-generation#5-high-fidelity-detail-preservation](https://ai.google.dev/gemini-api/docs/image-generation#5-high-fidelity-detail-preservation)
- Despite the "semantic negative" advice, the maker's own published example prompts do use plain negations and hard constraints: "No text." / "It is strictly important to keep identity consistent of all the 14 characters and items." / "Make sure to only have one of each character in each image." [https://blog.google/innovation-and-ai/technology/ai/nano-banana-2/](https://blog.google/innovation-and-ai/technology/ai/nano-banana-2/)
- Editing instructions should be blunt: "Editing Instructions: For modifying an existing image, be direct and specific." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- One thing prompting cannot fix: "The model won't always follow the exact number of image outputs that the user explicitly asks for." [https://ai.google.dev/gemini-api/docs/image-generation#limitations](https://ai.google.dev/gemini-api/docs/image-generation#limitations)
- Not in official sources: a separate negative-prompt parameter or "avoid" field; no such field is documented in the image-generation parameters.

## (e) Style transfer from a style reference

- The documented recipe: "Provide an image and ask the model to recreate its content in a different artistic style," using "Transform the provided photograph of [subject] into the artistic style of [artist/art style]. Preserve the original composition but render it with [description of stylistic elements]." [https://ai.google.dev/gemini-api/docs/image-generation#3-style-transfer](https://ai.google.dev/gemini-api/docs/image-generation#3-style-transfer)
- Multi-image style transfer holds the subject fixed: "Take the [element from image 1] and place it with/on the [element from image 2]… Ensure that the features of [element from image 1] remain completely unchanged." [https://ai.google.dev/gemini-api/docs/image-generation#5-high-fidelity-detail-preservation](https://ai.google.dev/gemini-api/docs/image-generation#5-high-fidelity-detail-preservation)
- Style must be described in words, not just pointed at: "Describe the artistic style, subject, and medium. Be specific about the visual detail (bold lines, colors, etc.) for consistent results." [https://ai.google.dev/gemini-api/docs/image-generation#2-stylized-illustrations-stickers](https://ai.google.dev/gemini-api/docs/image-generation#2-stylized-illustrations-stickers)
- Assigning one uploaded image the style role: "Use Image A for the character's pose, Image B for the art style, and Image C for the background environment." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Dedicated style-reference slots are only listed for Nano Banana Pro: "Up to 3 images to be used as style references", marked "N/A" for Nano Banana 2.1 / Gemini 3.1 Flash Image [https://ai.google.dev/gemini-api/docs/image-generation#use-14-images](https://ai.google.dev/gemini-api/docs/image-generation#use-14-images)
- Style is also given as a required prompt field of its own: "Style: What is the overall aesthetic? (e.g., 3D animation, film noir, watercolor painting, photorealistic…)" [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)

## (f) Text in images

- "Gemini excels at rendering text. Be clear about the text, the font style (descriptively), and the overall design. Use Gemini 3 Pro Image for professional asset production." [https://ai.google.dev/gemini-api/docs/image-generation#3-accurate-text-in-images](https://ai.google.dev/gemini-api/docs/image-generation#3-accurate-text-in-images)
- Template: "Create a [image type] for [brand/concept] with the text "[text to render]" in a [font style]." [https://ai.google.dev/gemini-api/docs/image-generation#3-accurate-text-in-images](https://ai.google.dev/gemini-api/docs/image-generation#3-accurate-text-in-images)
- Place and describe the lettering: "Specific text integration: Clearly state what text should appear and how it should look." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Two-step text workflow: "When generating text for an image, Gemini works best if you first generate the text and then ask for an image with the text." [https://ai.google.dev/gemini-api/docs/image-generation#limitations](https://ai.google.dev/gemini-api/docs/image-generation#limitations)
- Version note on text: Nano Banana 2 delivers "an upgrade from previous Flash image models with more reliable text rendering" and "in-image localization" [https://blog.google/innovation-and-ai/technology/developers-tools/build-with-nano-banana-2/](https://blog.google/innovation-and-ai/technology/developers-tools/build-with-nano-banana-2/)
- Known text weakness: "Visual and text fidelity: Rendering small text, fine details, and producing accurate spellings may not work perfectly." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Text can also leak into the output unprompted: "The model might create text as an image. To generate text, specifically ask for text output." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations)

## (g) Known limits and failure modes the maker admits

- Fidelity caps per workflow: "`gemini-nano-banana-2.1` and `gemini-3.1-flash-image` support character resemblance of up to 4 characters and the fidelity of up to 10 objects in a single workflow." [https://ai.google.dev/gemini-api/docs/image-generation#limitations](https://ai.google.dev/gemini-api/docs/image-generation#limitations)
- Output count is not reliable: "The model won't always follow the exact number of image outputs that the user explicitly asks for." [https://ai.google.dev/gemini-api/docs/image-generation#limitations](https://ai.google.dev/gemini-api/docs/image-generation#limitations)
- Ambiguous prompts can return text instead of a frame: "The model might only create text and no image if the prompt is ambiguous." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations)
- Truncated generations: "The model might stop generating content even when it's not finished." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations)
- Safety refusals: "If a prompt is potentially unsafe, the model might not process the request and returns a response indicating that it can't create unsafe images." [https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/gemini-image-generation-limitations)
- Style/lighting edits can go wrong: "Complex edits and image blending: Advanced editing tasks like blending or lighting changes can sometimes produce unnatural artifacts." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- Character consistency degrades with turns: "Character features: While usually reliable, character consistency across edits may vary." [https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/](https://blog.google/products-and-platforms/products/gemini/prompting-tips-nano-banana-pro/)
- The maker's fix for drift: "If you notice a character's features begin to drift after many iterative edits, you can restart a new conversation with a detailed description to retain consistency." [https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/](https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/)
- First-try accuracy is not promised: "achieving perfection on the first attempt with highly nuanced requests can require some iteration." [https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/](https://developers.googleblog.com/how-to-prompt-gemini-2-5-flash-image-generation-for-the-best-results/)
- Language limits: "For best performance, use the following languages: EN, ar-EG, de-DE, es-MX, fr-FR, hi-IN, id-ID, it-IT, ja-JP, ko-KR, pt-BR, ru-RU, ua-UA, vi-VN, zh-CN." [https://ai.google.dev/gemini-api/docs/image-generation#limitations](https://ai.google.dev/gemini-api/docs/image-generation#limitations)
- Everything is watermarked: "All generated images include a SynthID watermark." [https://ai.google.dev/gemini-api/docs/image-generation#limitations](https://ai.google.dev/gemini-api/docs/image-generation#limitations)
- One fixed limit that touches layout work: wide/panoramic tiling artifacts at 2K/4K on 1:4, 4:1, 1:8, 8:1 are listed as "Fixed" in 2.1, i.e. they existed in the previous version [https://aistudio.google.com/docs/models/gemini-nano-banana-2.1](https://aistudio.google.com/docs/models/gemini-nano-banana-2.1)

## What slowed me down

- `ai.google.dev/gemini-api/docs/image-generation` 301-redirects to `aistudio.google.com/docs/image-generation`, a JavaScript app: raw curl returns an empty shell, so the page had to be rendered (browser `read`) or taken from its Markdown twin. Anchors like `#best-practices` therefore live on a different host than the URL users are given.
- The Vertex AI image docs have moved: `cloud.google.com/vertex-ai/...` 301s to `docs.cloud.google.com/...`, and Gemini image pages now live under `gemini-enterprise-agent-platform/models/...` while the `vertex-ai/generative-ai/docs/image/*` pages are still Imagen-era (`imagen-3.0-generate-002` examples, Imagen 4 comparison tables) with almost no Gemini image prompting content. Several guessed paths 404'd.
- The prompting content is split across four different surfaces with no single canonical guide: the API page (templates), the cloud best-practices page (a one-screen restatement), the blog.google "7 tips" post, and a developers.googleblog post that is explicitly titled for Gemini 2.5 Flash Image — the oldest Nano Banana — not for Pro or 2.x. Version attribution had to be done per sentence.
- The Gemini API image page is one ~7,000-line document in which every prompt template is a code block inside tabbed widgets; templates are not in the prose, so they had to be extracted programmatically, and some headings (e.g. the numbered "Prompts for generating images" list) skip numbers in the extracted output.
- The "7 tips" post publishes its example prompts only as captions under images, without a compiled text list, so quotes had to be pulled from the rendered captions.
- Developers blog sitemap surfaced the 2.5-era prompting post but not a Nano Banana Pro prompting post; the Pro prompting post exists only on blog.google, found via its sitemap.
- No official page states outright that an input layout/composition is preserved exactly — the closest statements are template wording ("Preserve the original composition…", "remains exactly locked in its current position"), so that topic is thinner than the others.
